# 活动抽奖系统

一个组织者可以管理多场活动。电脑网页配置活动、导入名单和主持抽奖；参与者用手机浏览器或微信扫码打开报名网页；现场大屏展示中奖结果。数据保存在公司自有服务器的 SQLite 数据库中，不需要微信小程序账号或云部署。

![活动报名页与抽奖大屏示意](docs/mockups/activity-and-live.png)

## 功能

- 每场活动的参与名单、抽奖结果、报名字段和主题独立设置。
- 可选择导入名单、扫码报名或两者并用。每场活动自定义文本、手机号、数字字段，并指定一个必填字段作为去重依据。
- 多轮、多奖项、每个奖项自定义人数；每轮可设置前轮中奖者是否再次参与。同轮不会重复中奖，已抽奖项不会重复抽取。
- 可设置页面风格、主色、背景色，上传报名横幅、大屏背景和 Logo。
- 后台生成每场活动的报名链接和普通网页二维码。参与者可查看公开的中奖结果页。

## 本机启动

需要 Node.js 24 或更新版本。

1. 将 `.env.example` 复制为 `.env`。将 `ADMIN_PASSWORD` 设置为至少 12 位的强密码，`SESSION_SECRET` 设置为至少 32 位的随机密钥。不要公开或提交 `.env`。
2. 在项目根目录执行 `npm install`，然后执行 `npm start`。以后也可双击 [`启动抽奖系统.cmd`](启动抽奖系统.cmd) 启动，使用期间保持命令窗口打开。
3. 电脑浏览器打开 `http://127.0.0.1:3000/`，输入管理员密码。
4. 创建活动，配置字段、去重依据、轮次、奖项和主题，然后保存。
5. 在“活动信息”中打开报名页、复制报名链接或生成二维码。报名链接形如 `http://127.0.0.1:3000/event?id=活动ID`，结果页形如 `http://127.0.0.1:3000/results?id=活动ID`。

Windows PowerShell 示例：

```powershell
Copy-Item .env.example .env
# 用文本编辑器修改 .env 中的密码和密钥
npm install
npm start
```

默认仅监听 `127.0.0.1:3000`；数据库和上传图片位于 `./data`。可通过 `HOST`、`PORT`、`DATA_DIR` 环境变量调整。

`127.0.0.1` 只代表当前设备。若要用同一局域网的手机体验，可在 `.env` 中设置 `HOST=0.0.0.0`，允许该端口通过服务器防火墙，然后用电脑的局域网 IP 打开管理台并生成二维码。例如，电脑地址为 `192.168.1.20` 时，管理台地址是 `http://192.168.1.20:3000/`。手机须能访问此地址。

## 名单导入

后台“参与名单”选择 UTF-8 CSV 文件。Excel 可另存为 CSV UTF-8；首行写活动中的字段标识或显示名称，必填字段须有对应列。示例见 [`examples/participants.csv`](examples/participants.csv)。

一次最多导入 5000 行，文件上限 2 MB。系统统计新增、重复和无效行；去重字段去掉首尾空格、忽略英文字母大小写。已有参与者后，字段和去重依据会锁定，以保护原有名单。

## 公司服务器对外开放

1. 在公司服务器安装 Node.js 24，运行 `npm install`，配置 `.env`，将 `DATA_DIR` 指向有备份的持久目录。
2. 服务可继续监听 `127.0.0.1:3000`。用公司的反向代理和端口映射，将公网 **HTTPS 域名**转发到此端口。反向代理传递原始 `Host` 和 `X-Forwarded-Proto: https`。
3. 从公网 HTTPS 地址打开管理台，在“活动信息”中重新生成报名二维码。二维码编码的是当前打开管理台时显示的站点地址。若从 `127.0.0.1` 打开后台，生成的二维码也只会指向本机。
4. 活动前用手机关闭 Wi-Fi，通过移动网络扫描二维码，确认报名页、提交报名、结果页均可访问，再打开 `https://你的域名/live?id=活动ID` 检查现场大屏。备份 `DATA_DIR`。

公网发布涉及个人信息，务必使用有效 HTTPS 证书，并按活动需要告知参与者信息用途和保存方式。本项目未替公司配置域名、证书、端口映射或服务器防火墙。

## 抽奖规则

- 前一轮全部奖项抽完后才能进入下一轮。
- 每个奖项的结果只保存一次；再次请求会返回原结果。
- 抽奖开始后，轮次和奖项规则锁定。标题、主题和活动说明仍可更新。
- 大屏只读，主持人须在已登录的后台点击抽奖。
- 公开接口仅返回活动表单设置、参与人数和中奖结果；完整名单仅后台可查看。请将“中奖显示字段”设置为适合公开展示的内容，避免直接展示完整手机号等敏感信息。

## 当前限制

- 导入格式为 CSV；`.xlsx` 可先用 Excel 另存为 CSV UTF-8。
- 报名资格由活动自选的去重字段判断，参与者可以填写他人的去重值，不适合需要强实名核验的抽奖。
- 暂无多管理员权限、结果撤销、中奖通知和自动派奖流程。
- `miniprogram/` 和旧微信配置文档是此前方案的留存文件，当前网页报名流程不使用它们，也不需要微信 AppID 或 AppSecret。
