# 旧版小程序方案（当前不需要）

当前项目已改为手机网页报名和普通网页二维码。请以项目根目录的 [README](../README.md) 为准；以下内容仅供回看旧方案，不适用于当前二维码生成流程。

# 微信小程序配置指南（第一次使用）

这套系统分成三部分：公司服务器运行抽奖系统；微信小程序供参与者报名、查看结果；电脑浏览器负责管理和现场大屏。每场活动共用同一个小程序账号，在管理后台分别创建活动。

## 先准备 3 样东西

| 需要什么 | 从哪里来 | 用在哪里 |
| --- | --- | --- |
| 小程序 AppID | 微信公众平台的小程序后台 | 小程序项目文件和服务器 `.env` |
| 小程序 AppSecret | 微信公众平台的小程序后台 | **仅**服务器 `.env`，不要放入小程序代码或聊天中 |
| 公网 HTTPS 地址，例如 `https://lottery.example.com` | 公司网络/运维同事配置 | 小程序 API 地址、微信后台的服务器域名 |

## 第零步：公司还没有小程序账号时先注册

建议先由公司确定一名长期负责的小程序管理员，并准备公司可持续使用的邮箱、营业执照信息、管理员本人实名微信及手机号。主体核验可能还需要对公账户或其他材料，以微信注册页面的实际提示为准。账号应注册在公司主体名下，避免用员工个人主体承接公司的对外活动。

1. 打开[微信公众平台](https://mp.weixin.qq.com/)，点击 **立即注册**，账号类型选 **小程序**。
2. 填写公司准备的邮箱、密码，按收到的邮件完成邮箱激活。
3. 在信息登记页选择 **企业** 主体，按营业执照填写公司信息，指定管理员并完成页面要求的身份核验。提交前让公司核对主体名称。
4. 注册完成后，登录小程序后台，填写小程序名称、头像、简介，并选择与实际抽奖活动相符的服务类目。若后台提示认证或备案，再由公司管理员按页面要求办理；不要凭旧教程预付或选择与实际业务不符的类目。
5. 到 **开发与服务 → 开发管理 → 开发设置** 找到小程序 AppID。不要把公众号 AppID 当成小程序 AppID。

如果公司已有认证公众号，可先在其后台查看是否有复用主体资质注册小程序的入口；没有则按上面的普通注册流程即可。

## 先在本机模拟器测试（可暂时不做公网入口）

1. 在项目目录运行 `npm start`，确认电脑浏览器能打开 `http://127.0.0.1:3000/`。
2. 用微信开发者工具导入 `D:\ai_project\抽奖系统\miniprogram`，在工具的本机调试设置中临时勾选“开发环境不校验请求域名、TLS 版本及 HTTPS 证书”。
3. 先在电脑管理台创建活动，再在开发者工具添加编译模式：启动页面填 `pages/event/index`，启动参数填 `id=活动ID`。活动 ID 从管理台活动地址中获取。
4. 点击编译，在模拟器中检查活动信息和报名表。小程序代码在模拟器内自动连接本机 `http://127.0.0.1:3000`；真实手机仍不能通过这个本机地址访问。

## 第一步：请公司同事打通外网访问

把下面这段需求发给负责域名和网络的同事：

> 请为抽奖系统准备一个公网可访问的 HTTPS 子域名，例如 `https://lottery.example.com`。建议在运行 Node.js 的服务器上部署反向代理，由公司入口端口映射到该代理，再由代理转发到本机 `127.0.0.1:3000`；代理需要保留原始 Host，并传递 `X-Forwarded-Proto: https`。如果反向代理部署在另一台机器，请使用公司内网地址连接后端，并相应调整服务的 `HOST` 与防火墙规则。请确认活动现场使用手机流量也能访问该域名，服务器可以访问 `api.weixin.qq.com`，并安排 `data/` 目录备份。若域名或业务需要备案，请按微信后台当前提示处理。

公司提供公网端口映射即可自行部署，无需购买云主机；但正式小程序使用的接口仍需要公网 HTTPS 域名和有效证书。拿到地址后，先用手机流量打开 `https://你的域名/`，应出现管理后台登录页。不要把管理密码告诉参与者。

## 第二步：在微信后台取 AppID 和 AppSecret

1. 用小程序管理员账号登录 [微信公众平台](https://mp.weixin.qq.com/)。
2. 找到 **开发与服务 → 开发管理 → 开发设置**。界面名称可能调整，以页面上的 **AppID（小程序 ID）** 和 **AppSecret（小程序密钥）** 为准。
3. 复制 AppID。AppSecret 由管理员查看或生成，保存在公司密码管理工具中；它只需要填入服务器环境配置文件。
4. 在同一后台找到 **服务器域名**，将公司的 `https://你的域名` 添加到 **request 合法域名**。如果活动上传 Logo 或横幅，再按后台要求把同一域名添加到图片下载相关域名设置。

## 第三步：填写本项目的 3 处配置

1. 核对 [`miniprogram/project.config.json`](../miniprogram/project.config.json) 中的 `appid` 是否为当前小程序的 AppID；本项目已填入现有 AppID。
2. 打开 [`miniprogram/app.js`](../miniprogram/app.js)，把非模拟器分支的 `'https://your-domain.example.com'` 改为公司的公网 HTTPS 地址，例如 `'https://lottery.example.com'`。不要在末尾加 `/`。模拟器的 `http://127.0.0.1:3000` 保留用于本机调试。
3. 在**运行服务器的电脑**上打开项目根目录的 `.env`，填写：

   ```dotenv
   WECHAT_APP_ID=你的真实小程序AppID
   WECHAT_APP_SECRET=你的真实小程序AppSecret
   ```

   保存后重启 `npm start`。`.env` 包含管理员密码和密钥，不要截图、传群或提交到代码仓库。

## 第四步：在微信开发者工具导入、预览和发布

1. 从[微信开发者工具官方页面](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)安装工具，并使用有该小程序开发权限的微信登录。
2. 选择**导入项目**，项目目录选择 `D:\ai_project\抽奖系统\miniprogram`，核对 AppID 与项目文件一致。
3. 点击**编译**。在开发者工具中用活动 ID 打开 `pages/event/index?id=活动ID` 可预览活动页。活动 ID 在管理后台活动地址中可以找到。
4. 预览无误后，按开发者工具和微信公众平台当前界面的提示上传代码、提交审核并发布。开发版/体验版的访问人群由微信后台的成员与体验者设置决定。

开发者工具中的“不校验合法域名”只适合临时排查；最终请关掉这个选项，并使用真机确认 HTTPS 域名设置正确。

## 第五步：创建活动并验证二维码

1. 打开 `https://你的域名/`，用服务器 `.env` 中的 `ADMIN_PASSWORD` 登录。
2. 创建活动，设置报名字段、去重字段、轮次、奖项和主题；需要预选名单时导入 CSV。
3. 在活动信息页点击生成小程序码。若提示 AppID/AppSecret 错误，回到第二、三步核对；若提示网络错误，请公司同事检查服务器到 `api.weixin.qq.com` 的出站访问。
4. 用未连接公司 Wi-Fi 的手机扫码，填写测试报名；管理后台应看到参与人数变化。再打开 `https://你的域名/live?id=活动ID` 检查大屏。

正式活动前，请确认报名规则、隐私告知和收集字段符合公司的实际活动安排；不要在测试活动中抽正式奖项。

## 最容易混淆的地方

- `http://127.0.0.1:3000/` 只能从服务器本机访问；给小程序填写的是公司的**公网 HTTPS 地址**。
- AppID 可以填在项目文件里；AppSecret 只放在服务器 `.env`。
- 同一小程序可供多场活动使用，活动码中的活动 ID 决定打开哪一场。
- 小程序码生成成功只说明微信接口返回了图片；仍要在真实手机上确认能打开对应活动并提交报名。
