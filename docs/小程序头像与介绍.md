# 小程序头像与介绍

## 头像

文件：[小程序头像](../assets/miniprogram-avatar.png)

这是无文字的方形头像，适用于公司内部和对外活动。图案用星光、礼盒和两侧人物弧形表达活动聚集与奖品揭晓；深蓝背景配蓝金色，便于在小尺寸下识别。小程序名称尚未确定，因此头像没有加入名称。

## 微信后台介绍（推荐）

面向企业内部及对外活动，提供扫码报名、活动信息查看和中奖结果查询。

## 备用介绍

用于企业活动的现场抽奖与参与登记，支持扫码报名和中奖结果查看。

## 生成提示词

为通用活动报名与抽奖小程序生成一张 1:1 方形头像。中央为从打开的礼盒中升起的星光，两侧用简洁弧形表达参与者与庆祝氛围。深海军蓝背景，钴蓝与香槟金点缀，简洁、专业、温暖；小尺寸可辨识；无文字、无公司名称、无微信标志、无博彩元素、无水印。
